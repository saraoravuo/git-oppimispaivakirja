# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Alkuun oli hankalaa ymmärtää kaikkia uusia käsitteitä, joita tehtävänannoissa ja materiaaleissa käytettiin. Materiaalien kuvien ja toistojen kautta nekin alkoivat pikkuhiljaa tulla tutuiksi, ja ne myös auttoivat minua oppimaan. Perustoimintojen oppiminen oli helppoa, esim. git add, git commit tai git status. Myös uusien tiedostojen tekeminen ja nimien muokkaaminen oli suht helppoa, kun taas eri versioiden palauttamista tulee vielä kerrata.

Ongelmia tuli myös siinä mihin uuden tiedoston teen, ja missä repossa kulloinkin olen. Näiden kanssa jouduin alkuun säätämään ja pyytämään apua tekoälyltä. Se kuitenkin selitti missä meni pieleen ja neuvoi eteenpäin, joten sain hommasta kiinni!

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| mkdir | luo hakemiston |
| cd | siirtyy haluttuun hakemistoon |
| git clone | kopioi olemassa olevan repositoryn |
| git status | työhakemiston tiedostojen Git-tilan tarkastelu |
| git add | tiedosto lisätään talletukseen |
| git commit | muutosten talletus |
| git commit –m | muutoksen talletus kommentilla |
| git log | commit-talletusten historia |
| git rm | poistaa tiedoston paitsi työhakemistosta myös Git-hallinnasta |
| git mv | nimeää tiedoston uudelleen tai siirtää toiseen hakemistoon |
| git reset | add-komennon peruuttaminen |
| git restore | tehtyjen muutosten peruuttaminen ennen talletusta |
| git reset --hard | peruuttaa kaikki työtilaan tehdyt muutokset |
| git revert |  peruuttaa yhden talletuksen kerrallaan |
| git branch | näyttää olemassa olevat haarat |
| git switch  | vaihtaa haaraa |
| git merge | yhdistää haarat |
